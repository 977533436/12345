STM32F103RCT6开发板
1.USART串口通信实验:设计STM32F103RCT6开发板的USART串口通信实验：LED ON：常亮、LED OFF：熄灭、LED TOGGLE：闪烁、HELP：指令列表
2.独立按键控制LED实验：设计STM32F103RCT6开发板的独立按键控制LED实验：K2：常亮、K3：熄灭、K4：闪烁
3.定时器与中断控制实验：设计STM32F103RCT6开发板的定时器与中断控制实验：KEY1：启动/暂停 KEY2：切换闪烁间隔 0.5s → 1s → 3s → 0.5s KEY3：恢复默认

4.多功能电子时钟
时间显示：通过 OLED 显示当前时、分、秒。
时间调整：通过独立按键调整小时和分钟。sw2 sw3
时间运行：利用 STM32 定时器实现时间计数和更新。
闹钟设置：允许用户设置指定的闹钟时间。sw4进入设置界面
闹钟提醒：当当前时间达到设定时间时，蜂鸣器自动发出提示音。
闹钟关闭：通过按键关闭蜂鸣器提醒。sw4
界面显示：0.96寸OLED4针 I2C通信 显示当前时间及闹钟设置状态。
【操作说明】
正常显示：屏幕显示 HH:MM:SS 与闹钟时间 ALM hh:mm
KEY3 短按：NORMAL → SET HOUR → SET MIN → SET ALM H → SET ALM M → NORMAL
 KEY2 短按：当前设置项 +1（小时 0~23、分钟 0~59 循环）
KEY4 短按：当前设置项 -1
 闹钟响铃时按 KEY3：立即关闭声音并回到正常显示

6.STM32F103RCT6开发板的智能电子密码锁系统
密码输入：通过 4×4 矩阵键盘输入数字密码。
密码显示：0.96寸OLED4针 I2C通信 显示输入状态及操作提示
密码验证：STM32 对输入密码进行验证，判断密码是否正确。
开锁控制：密码正确时，STM32F103RCT6开发板 输出 PWM 信号控制舵机(SG90 180度)转动，模拟开锁。
错误报警：密码输入错误时，蜂鸣器发出提示音。
密码修改：用户通过指定操作进入密码修改模式，设置新的密码。
密码存储：将修改后的密码保存到 STM32F103RCT6开发板 内部 Flash，实现断电后密码保留。
